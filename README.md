# D-KEYS Desktop

Неофициальное desktop-приложение для пользователей D-KEYS на macOS и Windows. Написано на Rust с использованием GPUI.

> Это независимый порт оригинального Android-приложения. Команда D-KEYS не участвует в разработке этой версии, не отвечает за неё и не оказывает ей техническую поддержку.

## Возможности

- вход по номеру телефона и коду из SMS;
- сохранение сессии между запусками;
- список ключей с поиском по названию, адресу и коду;
- удалённое открытие двери с обязательным подтверждением;
- список камер и просмотр WebRTC внутри основного окна;
- онлайн-архив с выбором даты и быстрыми вариантами «Сегодня» и «Вчера»;
- автоматическое обновление серверов и списка устройств;
- отдельный экран с информацией о разработчике, хранении данных и ограничениях.

Внешний браузер, FFmpeg и RTSP-плеер не требуются. На macOS видео воспроизводится через WebKit, на Windows — через Microsoft Edge WebView2.

## Скачать

Готовые сборки публикуются на странице [Releases](https://github.com/iafilin/dkeys-desktop/releases/latest):

- `D-KEYS-Desktop-macos-arm64.zip` — macOS на Apple Silicon;
- `D-KEYS-Desktop-macos-x86_64.zip` — macOS на Intel;
- `D-KEYS-Desktop-windows-x86_64.zip` — 64-разрядная Windows.

На macOS распакуйте архив и перенесите `D-KEYS Desktop.app` в «Программы». Сборки не подписаны сертификатом Apple, поэтому при первом запуске откройте приложение через контекстное меню → «Открыть» и подтвердите запуск.

На Windows распакуйте архив и запустите `dkeys-desktop.exe`. Для камеры необходим WebView2 Runtime; на большинстве актуальных систем Windows 10/11 он уже установлен. При необходимости скачайте его с [официальной страницы Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

## Сборка из исходников

Требования:

- Rust 1.88 или новее;
- на macOS — Xcode Command Line Tools;
- на Windows — Visual Studio Build Tools с рабочей нагрузкой «Разработка классических приложений на C++».

```bash
git clone https://github.com/iafilin/dkeys-desktop.git
cd dkeys-desktop
cargo run
```

Релизная сборка:

```bash
cargo build --release --locked
```

Проверки перед отправкой изменений:

```bash
cargo fmt --check
cargo clippy -- -D warnings
cargo test
```

### Пакет приложения macOS

После `cargo build --release` выполните:

```bash
bash scripts/package-macos.sh
```

Готовый `D-KEYS Desktop.app` появится в каталоге `dist`.

## Данные и конфиденциальность

Приложение сохраняет телефон, токен сессии и кэш ключей в `session.json` в системном каталоге конфигурации. PIN-код не сохраняется. На macOS файлу назначаются права `0600`; не передавайте этот файл другим людям.

Для локальной отладки каталог конфигурации можно переопределить переменной `DKEYS_CONFIG_DIR`. Адреса API можно переопределить через `DKEYS_MDE_URL` и `DKEYS_CMDC_URL` — это служебные параметры для разработки, а не настройки для обычных пользователей.

Используйте приложение только с домофонами, камерами и другим оборудованием, к которому у вас есть законный доступ.

## Автоматические сборки

GitHub Actions проверяет форматирование, Clippy, тесты и release-сборку для Windows x64, macOS Intel и macOS Apple Silicon. Артефакты доступны в каждом запуске workflow.

Для публикации релиза обновите версию в `Cargo.toml`, создайте коммит и тег:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Workflow соберёт пакеты и создаст GitHub Release с автоматически сформированными примечаниями.
